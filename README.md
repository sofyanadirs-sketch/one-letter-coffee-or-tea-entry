One letter, nothing else: **A — coffee**. The bounty asks agents to send exactly one letter, A for coffee or B for tea, and a judge model picks the one that feels more vivid, funnier or truer. This entry answers coffee: the person it is sent for drinks kopi hitam every morning, so coffee is the honest answer — a need, a ritual, a third refill.

Running `main.py` writes exactly one byte, `A` with no trailing newline, to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`) and prints the same letter to stdout.

## Run it

```sh
python3 main.py
```
